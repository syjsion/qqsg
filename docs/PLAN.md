# QQ 三国局域网版开发计划

## 已确认的目标

2–4 人合作，Windows + macOS 客户端，macOS / Linux 独立常驻服务器。
尽量忠于原版体验，首发剑侍、仙术士，1–10 级，一个城镇和两张战斗地图。
基础数值默认 1 倍，服务器可调整经验与掉落倍率。仓库：<https://github.com/syjsion/qqsg>。

## 内容范围

巴郡 → 江陵西郊 → 营寨前门的小篇章编排。横版移动、跳跃、攀爬、换图、普攻和技能、治疗、三类小怪与邓茂、组队和聊天、背包和装备、商店补给、六个任务、死亡回城及持久进度。
地图采用原素材重建首版布局，连接关系是本项目编排，并非完整官方世界。
首版不含交易、拍卖、元神、副职、强化宝石、婚姻、军团和国战。

## 架构与交付

Godot 4.7.2 Standard / GDScript / Compatibility。ENet UDP 24567，60 Hz 模拟、20 Hz 快照，服务器权威；客户端本地预测、远端插值。不同地图独立状态、同服务器最多四人。
版本化 JSON 数据与原子存档；关键事务落盘后确认，30 秒周期快照和有效备份。
GitHub Actions 推送/PR/手动检查并输出 Windows、macOS 客户端及 macOS、Linux 服务端。默认 artifacts 保留 14 天，不自动创建公开 Release。

## 测试要求

单元测试验证数值、库存容量、奖励、事务回滚和存档恢复；多进程验证握手、移动、多人快照、版本拒绝、重复请求和重连。
真实 Windows + Mac 联机必须单独记录，不能用 headless 测试替代。

## 0.2.1 现有界面与物品表现

暂停新玩法开发，覆盖登录、HUD、背包、商店、强化、任务、队伍、聊天、设置、重连、死亡回城和交易确认；补齐地面物品贴图、NPC 任务/商店标记。采用原版风格木框、蓝绿底板、图标网格；文字保留名称、数值、剧情和错误原因。

背包 6×4，实际武器/护甲位与角色预览；单击详情、双击使用/装备、右键操作。购买/出售保持明确按钮、每次一件；不增加拖拽、卸装、批量交易及未实现的装备槽。复用原药品、铁剑、技能、格子及 NPC 图像；缺失素材通过 imagegen 内置工具生成并记录来源。角色动作、地图和战斗规则不变。

包/展示版本 0.2.1；协议 v3、内容 0.2.0、存档 v2 不变，可连接现有 0.2.0 服务端。验收包含全部图标映射、鼠标交互与事务待处理、逐页图形截图、完整回归和四目标导出。双机真实 LAN 验收仍单独记录。

## 0.3.0 副将招募与助战

赵云近战、黄忠远程、华佗治疗；允许同名独立收藏，最多 12 名、出战 1 名。完成初到巴郡后可领取独立名将同行任务，赠送赵云；邓茂个人奖励轮次有 50% 概率掉落招募令，在简雍附近自选招募。固定技能，战斗经验为主人击杀经验的额外 20%，副将等级不超过主人／10 级；暂不加入随机资质、装备、洗练、合成或附体属性。

服务端运行跟随、交战目标助战、治疗、受伤、倒下与脱战恢复；出战、收回、切换及放生需要脱战。新图像页面、HUD、三名角色动作和招募／技能图标齐全，维持现有点击交互。协议 v4、内容与包 0.3.0、存档 v3，支持 v1/v2 迁移并备份原始字节。

验收包含规则与事务回滚、同名实例、旧档迁移、四客户端招募重放／互见／个人 Boss 掉落／重启、真实图形截图及四平台导出启动；双机 LAN 继续单独验收。
